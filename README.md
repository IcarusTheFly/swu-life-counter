# SWU Life Counter

A life counter for *Star Wars Unlimited*.

Launches into a **Home** screen with **Start Game**, **Settings**, and (on Android/web) **Exit**. The Settings screen lets you pick a color for each side from an 8-color lightsaber-inspired palette (red, orange, yellow, green, blue, purple, pink, white), choose **Count Down** (start at a configurable value, default 30) or **Count Up** (start at 0), and set the starting life with a stepper or 20/25/30/40 quick-pick presets. Settings are persisted across launches.

## Development

```sh
npm install
npm run web        # browser preview (fastest dev loop)
npm run android    # Android emulator/device via Expo
npm run ios        # iOS simulator via Expo
npm test           # node-based unit tests (no install step)
```

## Regenerating the team-color backgrounds

The per-color background variants in `assets/bg_complete_<color>{,_landscape}.png`
are generated by a small Python pipeline — **not** hand-authored. To tune the
look (glow size, line sharpness, palette, etc.) or add a new color, edit the
constants near the top of [`scripts/generate_color_variants.py`](scripts/generate_color_variants.py)
and rerun it:

```sh
py scripts/generate_color_variants.py
```

See [`scripts/generate_color_variants.md`](scripts/generate_color_variants.md)
for the full knob-by-knob tuning guide and how to wire new colors into the app.
